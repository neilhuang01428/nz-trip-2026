## 五個先知道的重點

- **冰川健行改成庫克山健行**：不上冰川，改成走步道看冰川。9/28 一天看得到 Hooker、
  Mueller、Tasman 三條冰川，**步道免費、不用訂、不會被業者取消**，省下 NZ$3,596。
- **跳傘定在 10/01 皇后鎮**：NZONE，集合點在鎮上走路可到。代價是備案只剩 10/02 一天。
- **前四晚是滿月**：9/26–9/29 月面照度 99–100%，暗空保護區的觀星條件是全年最差。
- **有些東西吃不到**：Bluff 生蠔 10 月完全過季；Moeraki 的 Fleurs Place 已永久歇業；
  Mt Cook 唯一的餐廳我們在的兩天都公休。
- **10/08 必須改**：原行程那天純開車 7 小時以上，行程頁有三個修正方案。

## 地圖怎麼運作

網頁上的地圖是 **Leaflet ＋ OpenStreetMap**（不需要 API key）。
每張卡片與每個地圖 pin 都有 **📍 Google Maps** 按鈕，
用的是 Google 官方的 Maps URLs，**手機按下去會直接開啟 Google Maps App**，
接著按「儲存」就能加進你自己的清單。行程頁的每個路線方案還有一顆**導航按鈕**。

> ⚠️ Google 沒有開放「一鍵加入清單」的介面，所以最短路徑是兩個動作：開啟 → 儲存。

標「📍概略」的地點，地圖上是用鄰近地標推算的位置；**導航請按 Google Maps 按鈕**（那個是用店名精確搜尋）。
